# Bonus: Coding Problems

## Purpose
Practice coding problems commonly asked in data engineering interviews.
These are practical, real-world problems - not heavy algorithm puzzles.

## Difficulty Levels

### Easy
- String manipulation
- List/dict operations
- Basic file processing
- Simple data transformations

### Medium
- Data aggregation problems
- Nested data structure handling
- Implementing caching
- Stream processing

### Hard
- Complex data pipeline logic
- Concurrency problems
- Memory-efficient solutions
- System design components

## Interview Problem Types
- [ ] Parse and transform log files
- [ ] Aggregate data from multiple sources
- [ ] Implement rate limiters
- [ ] Build simple schedulers
- [ ] Data deduplication
- [ ] Merge sorted streams
- [ ] Implement LRU cache
- [ ] Batch processing logic

## Practice Strategy
1. Solve without looking at solutions
2. Time yourself (aim for 20-30 mins per problem)
3. Review and optimize your solution
4. Practice explaining your approach

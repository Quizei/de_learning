# Week 3: OOP, Data Classes & Design Patterns

## Topics Covered

### Concepts
- Classes and objects (revision)
- Inheritance, multiple inheritance, MRO
- Magic/dunder methods (`__init__`, `__repr__`, `__eq__`, `__hash__`, etc.)
- Property decorators and descriptors
- `@staticmethod` vs `@classmethod`
- Data classes (`@dataclass`)
- Abstract base classes (ABC)
- Common design patterns (Singleton, Factory, Strategy)

### Interview Focus
- When to use inheritance vs composition?
- Implement custom magic methods
- Data class vs regular class
- SOLID principles basics
